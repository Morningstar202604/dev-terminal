# DevTerminal UI/UX 与美术资源重构规范

> 定位：离线 Android Python/Java IDE。本规范面向移动端产品设计师 + 前端架构师，只写设计决策与交互说明，不含 Compose 代码。
>
> **设计信条（贯穿全文，不可妥协）**
> 1. **克制**：一屏只允许一个强调色焦点。状态用「色点 + 细字」，不用实心色块徽标。
> 2. **呼吸感**：用间距和明度分层，少画分割线；一根线只有在「间距不足以区分」时才画。
> 3. **信息层级清晰**：字重 + 字号 + 明度三件套拉开层级，不靠颜色堆砌。
> 4. **轻量快速**：能 120ms 反馈就不用 300ms；能不弹层就不弹层；编辑器是主角，一切外围元素都为它让路。
> 5. **单手可达**：高频动作（运行、输入、符号）落在拇指热区（屏幕中下部）。

## 任务一 · 视觉规范体系

### 1.1 色彩系统

全站**只有一个品牌强调色（indigo）**，辅助色（teal）仅用于「运行中」这一种进行态。其余状态全部用语义色，不许每个按钮各涂一色。

#### 1.1.1 品牌色阶（Primary / Indigo）

| token | 浅色 hex | 深色 hex | 用途 |
|---|---|---|---|
| `primary` | `#4A63D9` | `#8FA7F5` | 主按钮、激活态、链接、运行按钮 |
| `onPrimary` | `#FFFFFF` | `#101623` | primary 面上的文字/图标 |
| `primaryContainer` | `#E7EAFB` | `#232C45` | 主按钮弱填充、选中行底 |
| `onPrimaryContainer` | `#2C3F8F` | `#CBD7FF` | 容器上文字 |
| `primary-pressed` | `#3B51C0` | `#A6B8F8` | 按压态加深/提亮 6% |

> 不做 Material You 动态取色。工具类 App 颜色必须稳定，用户要的是「这是 IDE」而不是「这次主题随机长这样」。

#### 1.1.2 辅助色（Secondary / Teal，仅「进行中」）

| token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `secondary` | `#2F8F86` | `#6FD3C7` | 运行中状态点、流式输出光标、未保存点 |
| `onSecondary` | `#FFFFFF` | `#0A2B27` | — |
| `secondaryContainer` | `#E2F1EF` | `#16332F` | 极弱进行态底色 |

> 纪律：teal 全 App 只用于「正在运行 / 正在输入 / 有未保存改动」三类进行态。不拿它当第二个品牌色。

#### 1.1.3 语义色（补齐当前缺失的 success / warning / info）

| token | 浅色 hex | 深色 hex | 用途 |
|---|---|---|---|
| `success` | `#1E7E4E` | `#6FCF97` | 退出码 0、Git 已同步、保存成功 |
| `onSuccess` | `#FFFFFF` | `#08281A` | — |
| `successContainer` | `#E3F4EA` | `#12331F` | 成功提示底 |
| `warning` | `#9A6700` | `#E0A93B` | 运行超时、未配置 AI、Git 有未提交改动 |
| `onWarning` | `#FFFFFF` | `#2A1E00` | — |
| `warningContainer` | `#FCEFCB` | `#3A2E0E` | 警告底 |
| `error` | `#B23B32` | `#F08A82` | stderr、退出码≠0、删除确认、停止按钮 |

#### 1.1.5 表面层级（不依赖阴影）

| 层级 | 浅色 | 深色 | 承载 |
|---|---|---|---|
| base | N1 背景 | N8 背景 | 编辑器底层 |
| raised | N0 surface | N7 surface | 顶栏/Tab/状态栏/输出面板 |
| overlay | N3 containerHigh | N5 containerHigh | 底部弹层、对话框 |
| scrim | `#661B1F24` 40% | `#99000000` 60% | 弹层背后遮罩 |

> 工具类 App **不用 elevation 阴影**（除底部弹层极淡 1dp）。层级靠明度差，长时间看代码不刺眼。

#### 1.1.6 编辑器配色与 App 配色的协调

- 编辑器背景 = App `background`（深色 `#0E1013` / 浅色 `#FAF9F7`）或与它相差 1 个中性级，**消除编辑器与外壳之间的「一块板」接缝**。
- 6 套编辑器主题保留，但约束：关键字色板必须从「indigo / teal / 语义三色」里取派生色，不许出现高饱和荧光绿/粉。
- 编辑器的「错误下划线」=`error` @ 下波浪；「当前行高亮」=`primary` @ 6% 透明，不用实心黄条。
- stdout 用 `onSurface @ 88%`；stderr 用 `error`；系统/诊断行 `muted`；💡 友好提示 `secondary`。

### 1.2 字体系统（离线可用）

#### 1.2.1 字体栈

| 用途 | 栈 | 说明 |
|---|---|---|
| 中文 UI | 系统默认：`PingFang SC` / `HarmonyOS Sans SC` / `Source Han Sans` / `Noto Sans CJK`，回落 `sans-serif` | 不打包中文字体（数 MB，不值） |
| 西文 UI | 系统 `sans-serif`（Roboto/ OxygenOS 等） | 同上 |

### 1.4 图标系统

**现状问题**：全用 Material Icons 默认库——(1) outline 与 filled 线重不一（有的 2dp 有的 1.5dp），混用发虚；(2) 没有文件类型图标（.py/.java/.md 全是白纸）；(3) `AutoMirrored` 混用导致方向错乱；(4) 风格不统一（有的直角有的圆角）。

**规范**：

- **栅格**：统一 24×24dp，描边 **1.5dp**，圆角端点（round cap），圆角拐角。
- **outline / filled 混用规则**：
  - 默认一律 **outline**。
  - 仅两处用 filled：① 激活/选中态；② 主行动（运行 ▶、发送 ➤）。
  - 不允许一个界面里 outline 按钮旁边突然冒一个 filled 按钮。
- **尺寸**：顶栏 20dp、列表项 18dp、符号键字形 14sp、空态插画 40dp。
- **必须自建的自定义图标集**（矢量 drawable，tintable，约 18 个）：
  - 品牌：`ic_terminal_logo`（一个 `>_` 字形）
  - 文件类型：`ic_file_py`、`ic_file_java`、`ic_file_md`、`ic_file_html`、`ic_file_folder`、`ic_file_folder_open`、`ic_file_generic`、`ic_chevron_right`
  - 动作：`ic_run` / `ic_stop`（互斥一对）、`ic_symbol_bar_toggle`、`ic_split_view`、`ic_chevron_left`
- Material Icons 保留项：菜单、搜索、设置、关闭、保存、分享、删除、AI(AutoAwesome)、Git(AccountTree)、信息。这些仅作「够用就不画」，**不得再新增**引用——新图标一律走自定义集。

### 1.5 动效规范

沿用现有三档时长（已合理，固化）：

| token | ms | 用途 |
|---|---|---|
| fast | 120 | 按下反馈、状态点变色、键帽按下 |
| medium | 220 | 弹层淡入、Tab 切换、内容切换 |
| slow | 320 | 全屏页转场、抽屉开合 |

- 缓动：入场 `Cubic(0.05,0.7,0.1,1)`（快进慢出）；退场 `Cubic(0.3,0,0.8,0.15)`（慢进快出）；跟手拖拽用无回弹弹簧。
- 位移幅度上限 **12dp**，超过即视为「花哨」。

**不该用动效的场景（硬约束）**：
1. 输出流式打印——每来一行动画会掉帧，直接追加、不做 alpha 渐变。
2. 编辑器内文字滚动、光标移动、行号更新——即时响应。
3. Tab 内容切换——直接换，不 crossfade（切文件要够快）。
4. 双击/三击选中——系统默认，不叠自定义动画。
5. 列表快速滚动时不画 item 入场动画。

| `bg_pill_primary.xml` | 运行按钮 pill（圆角 20） | shape |
| `scrim_dim.xml` | 遮罩色 | color |

#### 1.6.2 矢量 vs 位图 / mipmap 策略

- **界面内一切图标、插画、形状：矢量 drawable**（缩放无损、自动随主题变色、包体小）。
- **位图仅一处**：启动器图标。用 adaptive icon（已有 `mipmap-anydpi-v26`），前景 `ic_launcher_foreground`（logo 安全区 66dp 内），背景 `ic_launcher_background`（品牌 primary 纯色）。为 API 24–25 兜底提供一张 `mipmap/ic_launcher.png`（192px）即可，不做多分辨率全套。
- **暗色限定符**：凡需要暗色变体的资源（目前没有插画需要变色——因为插画全部用 `?attr/color` tint 自动适配），仅 `bg_splash.xml` 若需深浅两套，放 `drawable-night/`。**原则：能用 tint 随主题的，绝不写 night 限定符资源。**

## 任务二 · 信息架构与组件体系

### 2.1 手机编程的核心动线

90% 使用时间只发生一条主回路：

```
选文件 → 写代码 → 点运行 → 低头看输出 → 点报错行跳回 → 改码 → 再运行
```

这条回路里，**编辑器必须永远是最大那块**，输出面板是第二主角（可折叠、可拖高），其余一切（文件树、Git、AI、设置）都是「召之即来、挥之即去」的临时层。

### 2.2 当前信息架构评估

当前结构 `抽屉文件树 + 顶栏 + Tab + 编辑器 + 符号栏 + 可拖输出 + 底部状态栏` —— **骨架是对的，保留**。问题在三处：

1. **导航入口太重**：10 个功能全塞在抽屉底部九宫格 + 顶栏塞到 4–5 个图标。
2. **所有面板都用居中 AlertDialog**：设置/Git/AI/全局搜索这种长内容，在手机居中弹窗里又小又挤，等于把桌面 Dialog 搬上手机。
3. **抽屉承担了两件事**：文件树（高频）+ 全部设置入口（低频），混在一个 272dp 面板里。

### 2.3 导航模式决策（单手操作）

- **不加底部 Tab 栏**。底部 Tab 会永久吃掉 ~56dp 编辑器纵向空间，而本 App 竖屏纵向本就紧张。文件树不是「一级目的地」，是工具。
- **保留 ModalNavigationDrawer 文件树**，但强化两个点：
  - 屏幕左边缘 **边缘滑动手势** 直接开抽屉（不只靠汉堡按钮）。
  - 抽屉顶部加 **项目切换器**（当前只服务一个项目，用户要切项目必须走「新建」）。
- **运行按钮保持顶栏右侧 pill**（可见性 > 拇指热区，因为它是用户视线落点；同时输出面板头部已有「重新运行」小按钮补全拇指热区）。
- **低频功能不抢位置**：设置、关于、自检、导出全部收进「命令面板 + 抽屉底部」，顶栏只留：菜单汉堡 / （可选预览开关）/ 运行 pill。

### 2.4 面板管理规则（重构 Overlay 的呈现形态）

当前「单 Overlay 密封类、同时至多一个面板」的**状态架构是对的，保留**。错的是呈现形态。按内容体量分三类：

| 形态 | 用在哪 | 规则 |
|---|---|---|
| **全屏页**（从右/下推入，占满，自带返回箭头） | 设置、关于、环境自检、新建项目(模板)、全局搜索、AI 对话 | 长表单/长列表/对话，需要完整屏幕。不遮罩背后内容，直接替换主区 |
| **底部弹层 ModalBottomSheet**（圆角顶 + 拖动条，最高 85% 高） | 文件操作(重命名/删除菜单)、运行配置、Git 提交信息、主题选择、字号选择 | 轻量、与当前任务强相关、看完即走。可上滑展开到全屏 |
| **居中 AlertDialog**（≤2 按钮，短文案） | **仅用于破坏性确认**：删除文件、丢弃未保存退出、Git 强制覆盖 | 绝不拿它装长内容。标题一行、正文两行内、按钮右置 |
| **常驻内联**（非 overlay） | 输出面板、查找条、符号栏、状态栏、stdin 输入行 | 一直在，靠高度/展开态管理 |

> Overlay 密封类保留，但每个分支声明自己的 `Presentation`（FullScreen / Sheet / Dialog），由统一容器决定怎么渲染，而不是每个分支手写一个 Dialog。

### 2.5 组件体系（原子 → 分子 → 组织）

#### 2.5.1 原子（Atoms）

| 组件 | 用途 | 变体 | 状态 |
|---|---|---|---|
| `AppButton` | 按钮 | primary(pill 实心) / secondary(描边) / text(无框) / danger(红) | default / pressed(@6% 加深) / disabled(38% 透明) / loading(内嵌 spinner 替代文字) |
| `AppTextField` | 输入框 | 标准 / 密码(AI key 可显隐) / 单行 / 多行 | default / focused(primary 1.5dp 边) / error(error 边 + 辅助红字) / disabled |
| `IconBtn` | 图标按钮 | 默认 20dp / 大号 24dp | default / selected(primary tint) / disabled(38%) |

## 任务三 · 全用户动线交互细节

> 每节固定覆盖：正常态 / 空态 / 加载态 / 报错态 / 离线态 / 键盘弹出 / 横竖屏。
> 时效口径：触觉反馈即时(<10ms 触发)、面板开合 ≤220ms、文件打开 ≤300ms、补全弹窗 ≤150ms。

### 3.1 首次启动 / 冷启动

- **Splash**：系统启动屏 `windowBackground` 直接画 background 纯色 + 居中 `ic_terminal_logo`（primary 色），**不做品牌动画**，停留到首帧可画即走（≤300ms）。
- **运行时解压进度**（首次）：大留白居中，圆环进度（stroke 2dp, 26dp）+ 一行说明 + 200dp 线性条 + 「首次启动需解压离线工具链」faint 小字。进度百分比不显示（解压是一次性、无网络，百分比意义不大）。
  - 解压中**禁止**任何返回键退出（防半途损坏）。
- **权限请求**：环境 READY 后才请求通知权限（Android 13+）。以**Snackbar 解释后再弹系统弹窗**：先给一次「允许通知才能在后台保持运行」的说明，用户同意才调系统框；拒绝则记标志，运行时在输出头给一次 warning 提示，不重复骚扰。
- **欢迎引导**：解压完首次进入 = 编辑器空态（三段式：一句话说明 / 新建项目主按钮 / 导入现有文件次链）。**不做轮播式多页 onboarding**——一页说清即可。
- 键盘态：首屏无输入框，键盘不弹。横屏：空态居中布局不变，插画略小。

### 3.2 新建项目

- 入口：抽屉九宫格「新项目」→ **全屏页**模板网格（当前 N 个模板：空白/Py 主入口/Hello/Py 类库/Java 主类/数据处理）。
- 模板卡片：一行文件名预览（mono 3 行）+ 名称 + 一句说明；选中态 primaryContainer 底。
- 命名：底部弹层输入项目名，实时校验（非空、不含 `/ \ : * ?`、不重名）；非法时输入框红边 + 下方红字，**主按钮 disabled**。
- 创建：按模板生成默认结构，**自动打开 `main.py`（或 `Main.java`）**，光标落最后一行，弹出键盘。
- 空态：模板列表为空时（异常）显示 illus + 重试。加载：建项目瞬间按钮 loading 120ms。报错：重名/IO 错 Snackbar error。离线：本功能纯本地，不依赖网络。

### 3.3 文件管理

- **文件树**：文件夹点击展开/折叠（chevron 旋转 120ms）；文件点击打开（300ms 内切 Tab）。
- **图标按类型**：`.py` 绿点角标 / `.java` 咖啡角标 / `.md` 蓝角标 / 文件夹 / 未知白纸——全部小尺寸，不抢戏。
- **新建**：文件树底部「+」→ 弹层选「文件/文件夹」+ 命名；新节点自动展开到可见并进入重命名态。
- **重命名**：长按节点 → 底部动作菜单（重命名/删除/在文件管理器定位）；重命名字段预选中旧名（去扩展名）。
- **删除确认**：**居中 AlertDialog**，标题「删除 main.py？」，正文「此操作不可撤销」，按钮「取消 / 删除(danger)」。删除有未保存改动的文件时正文追加警告行。
- **长按菜单**：同一长按弹层里给「复制路径」。
- **拖拽排序**：本期**不做**（手机文件树拖拽易误触，性价比低）。
- **隐藏文件**：设置里开关「显示 dotfile」，默认关；开启后 `.git` 等以 faint 色显示。
- 键盘态：重命名输入框弹键盘，文件树遮罩。横屏：抽屉变左侧固定栏（≥600dp 宽度时），不再是抽屉。

### 3.4 多 Tab 管理

- 打开文件即加 Tab；关闭点 ×；切换点击。
- **未保存标记**：文件名前 secondary 圆点（不用色块），切出脏 Tab 不自动保存（除非开了自动保存设置）。
- **Tab 溢出**：超过 5 个时 Tab 条横向滚动，**最右侧固定一个 `≣` 按钮**，点开底部弹层列出全部打开文件（含未保存标记 + 关闭按钮）。不做两行 Tab（太占纵向）。
- **Tab 长按菜单**：弹层给「关闭其他 / 关闭全部 / 复制路径」。
- **最近文件**：命令面板顶部「最近打开」section，最多 8 条。
- 关闭脏 Tab：若自动保存关，弹居中确认「放弃未保存改动？」。

### 3.5 写代码（编辑器核心）

- **光标/选择**：系统文本光标；双击选词、三击选行；选中文本弹系统编辑菜单（剪切/复制/粘贴），不自定义。
- **符号栏**：
  - 布局：紧贴系统键盘上方，一行横向滚动：`⇥`(accent) + `( ) [ ] { } : ; " ' = < > + - * / % _ # & | ! . , $ \` + `⌫`(accent)。
  - 高度 38dp，键帽描边 1dp（accent 键 primary 描边，其余 hairline）。
  - **可自定义**：符号栏最右一个「⚙」进入编辑，长按拖拽排序、可增删符号（设置里持久化）。本期至少把 `⇥` 和 `⌫` 固定不可删。
  - **键盘协同**：编辑器聚焦→键盘弹起→符号栏吸附键盘顶部；失焦→符号栏随键盘一起收起（不常驻，省纵向空间）。
- **双指缩放字号**：捏合实时改字号（10–24sp），松手 300ms 后落盘。
- **行号**：左侧 gutter，宽 32dp，右对齐，codeGutter 色；当前行号 primary 加粗。
- **缩进**：Tab 键插 4 空格（可设 2/4）；换行自动继承上行缩进。
- **代码片段**：命令面板「插入片段：XXX」插入；**不在符号栏塞片段**（太挤）。
- 键盘弹出态：编辑器区域自动压缩但当前光标行保持可见（系统 IME 调整）；输出面板被键盘顶到上方时可接受。横屏：符号栏在窄高横屏下缩为更矮一行（32dp）。

### 3.6 代码补全

- **触发时机**：输入标识符字符后 **250ms 防抖**触发；`.`（成员访问）立即触发。
- **候选展示**：编辑器光标上方浮起圆角列表（max 高 180dp，最多 6 条），每项 = 图标(函数/变量/关键字/模块) + 名称(mono) + 右侧类型(muted)。
- **选中方式**：↑↓ 键(符号栏上/下箭头，本期补全用键盘)、回车/Tab 确认、Esc/继续输入关闭。
- **无结果态**：不弹空框（直接不显示），避免每打一键闪一下。
- **补全来源**：本期纯**静态词表**（当前文件 token + Python 关键字 + 内置库词表）。LSP 标注为远期，UI 预留「来源角标」位置（静态=无角标，LSP=小 `L` 点）。
- 报错态：补全崩溃时静默降级为纯词表，不打断输入。

### 3.7 运行

- **运行按钮三态**：
  - 可运行：pill「▶ 运行」primary 实心，无文件时 disabled(faint)。
  - 运行中：变「■ 停止」error 描边。
  - 首次运行解释器预热：输出区首行打印 muted 提示「首次运行正在预热解释器…」，预计 1–3s，不阻塞按钮。
- **运行前自动保存**：脏文件点运行→先静默保存（不弹确认），再跑。
- **运行配置**：命令面板「运行配置」→ 底部弹层：参数输入（空格分隔）、Java 主类选择。
- 加载态：运行中顶栏 pill 内加细进度条纹（不转圈，转圈太焦虑）。报错态：见 3.10。

### 3.8 看输出

- **流式展示**：stdout 逐行追加到 LazyColumn，**无动画**；运行中自动跟随滚动到底。
- **自动滚动锁**：用户手动上翻历史时，**暂停自动滚动**，输出头出现一个「↓ 回到底部」小按钮；点回后恢复。
- **着色**：stdout onSurface@88%；stderr error；系统行 muted；💡 友好提示 secondary。
- **过长处理**：输出最多保留 **5000 行**，超出丢弃最旧并在头一行插 muted「…已截断 N 行」。
- **操作**：头部三个图标 = 分享 / 重新运行 / 清空；**字号切换**放进长按头部或「⋮」菜单（10/11/12）。
- 空态：输出为空显示「点击 ▶ 运行，输出会显示在这里」faint 提示。
- 横屏：输出面板变右侧 36% 栏。

### 3.9 交互输入（stdin）

- 程序调 `input()` → 输出面板底部升起一行输入框，**自动聚焦并弹键盘**，placeholder「程序在等你输入…」。
- 输入行前面一个 `›`（secondary 色），右侧发送键(primary)。**整行提交**（回车即发，不逐字符回显）。
- **历史输入**：输入框上滑或点「↑」调出历史（最近 10 条）。
- **等待提示**：输出头状态点变 secondary 呼吸 + 「等待输入」细字。
- **超时**：运行超时设置（默认 10s 可改）到点自动停止，输出 warning「运行超时，已强制终止」。
- 键盘态：输入框紧贴键盘上方。退出键盘回到 App 时输入行保留草稿。

### 3.10 看报错

- **traceback 格式化**：stderr 整体 error 色；内置 20+ 高频错误在末尾追加一行 secondary 色 `💡 可能原因：…`（已有翻译能力，UI 上固定为「错误行 + 一行人话解释」两行块）。
- **可点击跳行**：含 `line N` / `file.ext:N` 的行渲染为可点，带下划虚线；点击→收起键盘、编辑器滚到该行、该行背景 primary@6% 高亮 1.5s 后渐隐、光标落该行。
- **联动高亮**：跳转后输出面板不关闭（竖屏它在下方，编辑器在上），视线自然下移看报错。
- **复制报错**：报错行长按 → 菜单「复制报错」。
- 空态/正常态：无报错不显示任何红色。

### 3.11 改码 → 重跑

- 跳行后光标已就位，用户直接改。
- **修改后快捷入口**：输出头「重新运行」按钮常驻（primary 小图标），不用回顶栏。
- **撤销/重做**：编辑器长按菜单里保留系统撤销/重做；符号栏**不**放撤销重做（省位置）。
- 连续「运行→报错→改→运行」闭环全程不离开单屏，是本 App 的核心爽点。

### 3.12 查找替换

- **当前文件**：顶栏命令或命令面板调出 FindBar（贴 Tab 条下方）。
- 字段：查找框 + 替换框（点「替换」开关展开）；右侧计数 `3/12`；上一个/下一个（primary）；正则 `.*`、大小写 `Aa`、全字匹配三个切换按钮（激活=primary tint）。
- **高亮**：编辑器内全部命中 faint 底，当前命中等 primary 框。
- **替换**：「替换一处」逐处；「全部替换」前不二次确认（撤销可回退），完成后 Snackbar「已替换 N 处」。
- **全局搜索**：全屏页，输入即搜（防抖 300ms），结果按文件分组、每条 `文件名:行号  匹配行预览(命中词 primary)`；点击直接打开并跳行。无结果显示 illus + 「未找到 X」。
- 键盘态：查找框弹键盘时编辑器不遮罩。

### 3.13 版本管理（Git）

- **状态展示**：文件树节点右侧小圆点——已修改(M) warning 黄、未跟踪(?) secondary、暂存(+) success。
- **入口**：抽屉「Git」→ **全屏页**：变更文件列表（可点看 diff，左右并排只读 diff，删除行红/新增行绿）+ 提交信息输入框 + 「提交全部」主按钮 + 「推送 / 拉取」次按钮。
- **进度与结果**：push/pull 中按钮 loading；成功 Snackbar success「推送完成」；失败 Snackbar error + 显示远端输出。
- **冲突**：检测到冲突 → 顶部 warning 横幅「存在合并冲突，请手动解决后再提交」，冲突文件行红色标注。
- **未配置引导**：首次进 Git 页若无 user.name/email，显示设置卡片（底部弹层填），配好才可提交。
- 离线态：Git 提交/提交历史纯本地可用；push/pull 需网络，无网时按钮 disabled + tooltip「当前离线」。

### 3.14 导入导出

- **导入**：抽屉「导入」→ 系统 SAF 选文件（`*/*`）→ 落到当前项目根目录，重名自动加 `(1)`。完成 Snackbar「已导入 xxx.py」。
- **导出单文件**：SAF CreateDocument，默认名 = 文件名；导出成功 Snackbar。
- **批量/整项目**：命令面板「导出整个项目为 ZIP」→ SAF 选位置打包 `.zip`。
- 空态：无文件时导出按钮 disabled。

### 3.15 设置

- **形态**：全屏页，分组列表（不居中弹窗）。
- 分组：
  1. **外观**：主题(系统/浅/深 分段，切换**实时预览**无需重启)、编辑器主题(6 选 1 色卡)、编辑器字号(滑块 10–24)。
  2. **编辑器**：自动保存(开关)、Tab 宽度(2/4)、符号栏自定义入口。
  3. **运行**：超时秒数(10/30/60/∞)。
  4. **AI**：BaseURL / API Key(密码框可显隐) / 模型名；**国内模型优先**预设 chips（DeepSeek / 通义 / 智谱 / OpenAI 兼容），点 chip 自动填 BaseURL。
  5. **关于**：版本、开源许可、开源致谢。
- 每项 = `SettingRow`（左标题+副文 / 右控件）。
- 离线态：AI 配置未填时，AI 入口给 illus_offline 引导，不报网络错。

### 3.16 AI 助手

- **形态**：全屏页对话（从底部弹起至 85%），不是小弹窗。
- **上下文**：顶部 chips 显示本次附带的上下文——「当前文件 main.py」「选中 3 行」「最近报错」，可点 × 移除。
- **快速指令**：输入框上方一行 QuickChip 横滑——解释代码 / 修复这个报错 / 生成测试 / 加注释。
- **流式输出**：逐字渲染 markdown，最后一个字符后加 secondary 呼吸光标；markdown 用内置渲染器（离线）。
- **未配置引导**：未填 Key 时显示 illus_offline + 「去配置」按钮跳设置 AI 区。
- **插入结果**：代码块右上角「插入到光标」按钮，把代码块写回编辑器。
- 离线态：无网时发送按钮 disabled +「AI 需要联网，当前离线」。

### 3.17 Markdown / HTML 预览

- 顶栏「预览」开关（仅 .md/.html 出现）→ 编辑器与预览**左右/上下对半分屏**（竖屏上下，横屏左右），中间一条 hairline。
- **刷新时机**：编辑停止 350ms 后重渲染（防抖），切文件立即渲一次。
- **暗色适配**：WebView 跟随 `effectiveDarkTheme()` 注入深色 CSS。
- **图片**：本地相对路径加载；远程图片无网时显示占位框，不崩。
- 空态：md 为空显示「预览将在这里显示」。

### 3.18 会话恢复

- 进程被杀后冷启：恢复上次打开的 Tab 列表、每个文件的**光标位置与未保存 buffer**（不只存磁盘上的版本）、输出历史保留最近 200 行、不自动恢复运行态（运行态必丢，提示「上次运行已中断」）。
- 恢复在 READY 后 300ms 内静默完成，不打断。

### 3.19 前台服务与通知

- 运行中起前台服务，通知：标题「DevTerminal 正在运行」+ 内容 = 当前文件名 + 一个「■ 停止」动作按钮。
- 通知点击回到 App。
- 后台保活：靠前台服务 + 通知；通知权限被拒时，退到后台仍尽量跑，但在运行结束时输出一行 warning「未授予通知权限，后台可能被系统回收」。

### 3.20 退出

- 返回键优先级链（由内到外）：关闭弹层 → 关闭抽屉 → 若有脏文件弹居中确认「有未保存改动，退出？」(取消/保存并退出/不保存) → 否则直接退。
- 退出前 `ON_STOP` 自动落盘 buffer。
- WebView 资源（预览/AI markdown）在退出时 `onPause` 释放，避免泄漏。
