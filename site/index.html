为什么值得你点 Star

Termux 是黑框终端、Pydroid 装包要联网、Acode 跑不了真代码——DevTerminal 把「真离线」和「现代 IDE」一起做到了手机上。

原生引擎，不是模拟

内置 CPython 3.13.9（PEP 738 官方 Android 支持），原生 ARM64 编译，无 WASM 降速。真文件系统、完整 traceback、input() 交互、死循环可中断——桌面 Python 能写的这里都能写。

开箱即用，装完即离线

Python 解释器与标准库随 APK 打包，首次启动秒级解压。Git（JGit）、Markdown 预览、语法高亮全部内置，飞行模式下装上就能写。

现代 IDE 体验

26 键快捷符号栏、多文件 Tab、全局搜索、正则计数跳转、双指缩放字号、报错行点击直达源码，还有 Git 面板与分屏预览。
